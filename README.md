# 🎨 AI Image Generator

An AI-powered image generator built using **Python, Streamlit, and Hugging Face Diffusers**.

The application allows users to enter a text prompt and generates an image based on the description using a text-to-image AI model.

## 🚀 Features

- Generate images from text prompts
- Simple and user-friendly Streamlit interface
- Uses Hugging Face Diffusers
- Supports AI-based text-to-image generation
- Displays the generated image directly in the application

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Diffusers
- Transformers
- PyTorch
- Stable Diffusion
